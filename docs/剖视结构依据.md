# 剖视结构依据

核实日期：2026-10-01。目录为 [src/interior-data.js](../src/interior-data.js)，仅提供可引用的结构事实与不确定性，不代表这些内容已全部建模。内部图例颜色是教学标识，不是推进剂真实颜色或实际材料涂装。

`getInteriorSpec(rocketId, partId)` 返回字符串标签、储箱顺序、来源 ID、置信状态、说明与特征列表。`confirmed` 仅表示条目列出的公开事实得到支持，不表示内部坐标、比例、容积或整个三维模型经过工程验收。`schematic` 表示存在未核实的结构映射或构型差异。非贮箱部件的 `order: unknown` 表示顺序不适用；不能因此给发动机、整流罩或飞船随意补上双贮箱。

## 储箱与推进剂

| 构型 / 部段 | 燃料与氧化剂 | 当前顺序结论 | 可据此表达的结构 |
| --- | --- | --- | --- |
| F9 一级、FH 中央/侧芯级 | RP-1 / LOX | 氧化剂在上 | 共底穹顶、穿过煤油箱的双壁输氧管、九机承力区域 |
| F9/FH 二级 | RP-1 / LOX | 氧化剂在上 | 缩短版贮箱、燃料箱底部接口、单台 MVac |
| Super Heavy V3 | 液态甲烷 / LOX | 燃料在上 | 燃料箱前穹顶、集成热分级、向发动机输送燃料的管道 |
| Ship V3 | 液态甲烷 / LOX | 未确认 | 主箱、header 储供系统、载荷区域分别处理；不套用旧版 header 位置 |
| CZ-5/CZ-5B 芯级 | LH₂ / LOX | 未确认 | 氢氧推进剂区；一级有氢箱、箱间段、氧箱部段 |
| CZ-5/CZ-5B 助推器 | 煤油 / LOX | 未确认 | 与氢氧芯级不同的煤油助推动力体系 |
| CZ-7 两芯级及助推器 | 煤油 / LOX | 未确认 | 一级部段、二级四机共架、单机助推器 |
| CZ-8 一级及助推器 / 二级 | 煤油/LOX；LH₂/LOX | 未确认 | 区分煤油下级与氢氧上级；不套用八号甲 |
| CZ-2F 两芯级及助推器 | UDMH / N₂O₄ | 未确认 | 常温推进剂贮箱、仪器舱、主机与游动系统 |

“未确认”是本轮证据范围不足，**不是断言不存在确定的实物布局**。渲染端如需摆放，应明确标记“教学布局，储箱上下顺序待核实”，或以不暗示实际顺序的功能示意展示。不能通过“所有火箭通常如此”补全，也不能从外壁结霜、涂装或非官方爱好者剖面直接认定。

## 猎鹰 9 号与猎鹰重型

[SpaceX 2025-05-09 用户指南](https://www.spacex.com/assets/media/falcon-users-guide-2025-05-09.pdf)第 2.2–2.4 节（印刷页 6–10）是主要依据：LOX 穿箱管通往发动机、二级燃料箱底部连接关系与缩短版储箱说明共同支持上述布局。一级八台外围发动机围绕中央一台；FH 使用三芯级，但中央芯级有加强设计。

**级间段应表现为复合材料筒壳及内部连接界面，不能把任意裸露大桁架当作外观。** 指南公开了铝蜂窝芯/碳纤维蒙皮、三处机械锁扣和四个气动推杆。它没有给出本模型所需的每根管、每块支架、箱壁或螺栓尺寸。

[NASA 商业载人计划资料包](https://www.nasa.gov/commercial-crew-program-press-kit/)可辅助核对整体组成、九台一级发动机和贮箱材料。其载人构型图不能直接替代本游戏卫星整流罩载荷；引用 NASA 资料不代表游戏或模型获得 NASA 认证。

## 星舰 V3

[SpaceX V3 更新说明](https://new.spacex.com/updates)指出助推器燃料箱前穹顶直接面对 Ship 点火环境，并描述燃料输送管和集成热分级设计。本目录将 Super Heavy 的前部燃料箱关系记为已确认，但不推导其全部管径或箱长。[第十二次试飞说明](https://www.spacex.com/launches/starship-flight-12)支持 V3 的 33/6 发动机、四襟翼与再入热防护构型。

[FAA 2023 补充材料](https://www.faa.gov/media/27271)附件的早期 Starship 剖面标出了主燃料箱、主液氧箱、header tanks、共底与供给管。**它是早期构型材料，不是 V3 完整内部图。** 本轮不把该图的尺寸、header 位置、数量或细节搬到 V3。V3 官方更新确认 header 供给系统改进，仍不足以确认整个 Ship 内部布局。主箱、header 系统和载荷舱应是不同概念，不能堆成同一组“油箱”。

## 长征系列

[长征五号官方构型](https://www.cnsa.gov.cn/n6758824/n6759008/n6759011/c6794064/content.html)区分氢氧芯级与液氧煤油助推器；[一级总装报道](https://www.cnsa.gov.cn/n6758823/n6758838/c6770161/content.html)确认氢箱、箱间段、氧箱部段。[助推器研制论文](https://jdse.bit.edu.cn/sktcxb/cn/article/id/58c21589-a86b-48db-b547-a5533573fda7)可进一步追溯低温贮箱、绝热及承力技术，但本轮未从完整剖面完成顺序核验。不得由“氢氧火箭”推定所有部段都采用同一共底结构。

[长征五号 B 发布会](https://www.cmse.gov.cn/ztbd/xwfbh/202005/t20200519_46641.html)明确取消芯二级。其大型整流罩内是载荷空间，不应画出不存在的二级储箱。

[长征七号结构介绍](https://www.cmse.gov.cn/kpjy/htzs/ttsj/201509/t20150911_37325.html)给出一级部段名称和液氧煤油动力；[研制团队机架报道](https://www.spacechina.com/n25/n2014789/n2014809/c3810383/content.html)确认二级四台发动机共架。部段列表在本目录中未被扩展成精确剖面坐标。[长征八号基本型说明](https://www.spacechina.com/n25/n146/n238/n12985/c3961239/content.html)确认其一级/助推器煤油、二级氢氧，不能将两级全部画成同种推进剂。

[长二 F 结构介绍](https://www.cmse.gov.cn/kpjy/htzs/ttsj/201509/t20150911_37314.html)的前半部分明确传统载人构型的 UDMH/N₂O₄、仪器舱圆盘和动力组件。该页末尾混有新型换发方案文字，本目录不将其液氧煤油描述混入传统长二 F；二级主机与游动单元可用[国家航天局组成解读](https://www.cnsa.gov.cn/n6758824/n6759009/n6759042/n6759070/c6795735/content.html)交叉核对。

## 载荷、飞船与内部展示

[空间站阶段神舟/天舟构型比较](https://www.cmse.gov.cn/xwzx/202302/t20230223_52828.html)确认：神舟为轨道舱、返回舱、推进舱，天舟为货物舱和推进舱。[2015 神舟总体布局资料](https://www.cmse.gov.cn/art/2015/9/11/art_944_20867.html)公开返回舱座椅及仪表、轨道舱安装板和推进舱设备圆盘，可引用为功能模块示例；不能据此宣称复原了当前神舟任务的所有内装。

本游戏其他演示卫星、大型舱段和星舰舱内载荷尚未锁定实物型号，其内部不能标为“真实结构”。可显示一般承力接口、设备功能区，但不补造舱内座椅、电子盒、贮箱或管路，再将其称作一手资料还原。

下一轮应先锁定具体任务及硬件批次，再为每个几何对象记录“来源图号或段落—可确认事实—采用尺寸—尚未验证内容”。现有证据足以修正明显的推进剂混用和连接关系，但不足以支持全部内部 1:1 工程精度。

## 剖切面的补充表达

剖视不再只删除朝向观察者的表面。移动剖面时，模型按现有舱壁轮廓重新计算截面；切到穹顶或靠近外壁时，截面随之收窄。公开布局已确认的储箱使用功能颜色表示介质区，并显示薄壁与共底轮廓。颜色不表示液体真实颜色、任务中的液位或加注比例，壁厚也为清晰辨认而做了示意处理。

未知储箱顺序仍不分成上下两个彩色箱体，只显示一片半透明的中性舱区截面。级间段保留中心空间，以环框、周边支撑和已有连接件解释结构；整流罩只补壳层的剖切边，不用实心盖板堵住载荷空间。猎鹰标准罩的内衬层参考用户指南第 4.1.3 节中带声学内衬的配置，不代表所有实飞任务具有完全相同内衬。

[NASA Glenn 的液体火箭发动机说明](https://www1.grc.nasa.gov/beginners-guide-to-aeronautics/liquid-rocket-engine/)支持“推进剂经泵和供给流路进入燃烧室、再由喷管排出”的功能关系。剖视新增的泵壳与供给连接是代表性教学组件，不表示某型发动机实际采用的泵组数量、循环形式或安装坐标。喷管流道保留开放，不将喷管、格栅翼或其他实际空腔一律填实。

截面、壳层与内部示意均由剖视控制器单独持有，关闭剖视恢复原材质，模型的原始几何与外形尺寸不因剖面补充而改变。API 保持原有启用、偏移、单模块聚焦、更新和释放接口。
