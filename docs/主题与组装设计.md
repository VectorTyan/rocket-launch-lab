# 主题与组装设计

主题配置位于 [studio-themes.js](../src/studio-themes.js)，供“结构探索”和“火箭组装”共用。发射模式继续使用所选发射场的天空、地形和任务光照。

## 四种展台

| 主题 | 画面方向 | 适合的操作 |
| --- | --- | --- |
| 科技展厅，默认 | 明亮蓝灰背景、清晰轮廓、浅色面板 | 观察整体、读模块说明、查看剖面 |
| 摄影工作室 | 暖白背景与柔和补光 | 比较金属、黑色部件和连接处 |
| 火箭小工坊 | 奶油与天空色，控件容易辨认 | 自由拼装、反复尝试 |
| 星空展台 | 较亮的蓝紫背景、少量星点 | 观看拼好的火箭并绕着观察 |

主题只改变展台、灯光和界面颜色，不替换火箭的真实配色，也不改变剖视图例中“燃料、氧化剂、未知舱区”的含义。白色箭体要与背景有边界，黑色隔热层与发动机也要有足够补光。配置是调校起点，接入后仍需分别观察明暗部件和文字可读性。

## 组装怎么好玩

把部件拖到相近的正确位置时，显示轮廓提示，松手后轻轻吸附到位。位置不对时让部件回到可继续操作的地方，不扣分，也不弹出“失败”。不方便拖动时，可以先点击一个部件，再点击发光位置，或用“装上这一块”完成同样的动作。细小部件周围也可以拿起，目标位置有容差。

没有倒计时惩罚。随时可以查看提示、撤销上一步或重新开始。提示先指一指合适的位置，再按需要给更明确的帮助；孩子可以自己试，也可以和大人一起拼。

每装好一个模块，说一句简短知识，例如“整流罩帮助保护里面的卫星”或“这台火箭没有第二级”。不要求背名称或答题才能继续。不同型号只提供实际存在的模块，避免为了拼装步骤给长征五号 B 增加二级，或给星舰增加两瓣整流罩。

拼好后给一个清晰的“我的火箭，出发！”按钮。点击后带着当前型号进入发射控制，在兼容场地从新任务倒计时开始。也可以选择“欣赏作品”留在工坊，或“再搭一次”重玩。进入结构或组装会暂停正在飞行的任务。

## 接入边界

- 默认选择“科技展厅”；找不到已保存的主题时也回到这一主题。
- 结构和组装共用主题，但各自保留明确的操作状态。进入组装时退出剖视、隔离和展开观察，避免外壳缺半边或部件刚拖动就被观察动画放回原处。
- 拖部件时暂停镜头旋转，松手、取消触控或移出窗口后恢复。吸附范围考虑当前缩放，点击辅助始终可用。
- 切换型号前结束当前拖动，移除旧型号的可点击对象和目标位置；完成计数按该型号的真实模块重新建立。
- 主题切换不重置拼装进度，也不移动已放好的部件。返回发射时完整恢复发射场光照、雾、环境贴图、镜头限制与界面配色。
- 界面需把提示、撤销、主题选择和“去发射”放在可滚动或可见区域。浅色背景下同时调整文字、边线和焦点样式，不能只把背景变亮。

实现与实际检查见 [验证记录](验证记录.md)。桌面鼠标拖放和按钮流程已检查；尚未完成触摸屏、多指交互及低性能设备的实机验收。
