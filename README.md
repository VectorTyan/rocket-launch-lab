# 卡门线 KÁRMÁN · 火箭发射实验室

在本地浏览器中选择火箭与兼容发射场，触发点火，切换镜头观看上升、分离与任务结束过程，也可以进入结构模式拆解、聚焦和单独查看模块。

当前提供 **8 款火箭、7 个可用发射工位、6 种机位和标准／电影两档画质**。官方公开的整体尺寸与主要构型用于建立比例，模块细节、场景布局和飞行轨迹仍是科普示意，仪表不是真实遥测。型号、场地与资料边界见 [火箭与场地资料](docs/火箭与场地资料.md)。

## Windows 启动

使用 Node.js 22.12+ 或 24 LTS，并确保 `node`、`npm` 已加入系统路径。依赖版本以 [package-lock.json](package-lock.json) 为准，已验证的运行环境见 [验证记录](docs/验证记录.md)。

**最简单的方式：双击 [start-local.cmd](start-local.cmd)，保留启动窗口，然后打开显示的本地地址。**

在项目目录中右键 [start-local.ps1](start-local.ps1)，选择“使用 PowerShell 运行”；也可以在 PowerShell 中执行：

```powershell
.\start-local.ps1
```

脚本会检查 Node.js 和 npm；首次运行时，如果没有 `node_modules`，会用 `npm ci` 按锁定文件安装依赖。安装失败会停止，不会继续启动。首次安装需要网络；已经安装的依赖与游戏资源从本地加载。

启动后，在浏览器中手动打开 [http://127.0.0.1:5173](http://127.0.0.1:5173)。脚本默认不自动打开外部浏览器。运行时保留终端窗口，按 `Ctrl+C` 停止服务。如果 5173 端口被占用，启动会报告错误，不会自动换到其他端口。

若 Windows 因脚本执行策略而阻止运行，可以使用下面的手动命令，不必修改全局执行策略。

## 手动运行与构建

在项目目录的终端中执行：

```powershell
npm.cmd install
npm.cmd run dev -- --port 5173 --strictPort
```

以上分别对应 `npm install` 与 `npm run dev`；在 Windows PowerShell 中使用 `npm.cmd` 可以避免误调用受执行策略限制的 `npm.ps1`。复现锁定的依赖树时，用 `npm.cmd ci` 替代 `npm.cmd install`。

其他命令：

| 命令 | 用途 |
| --- | --- |
| `npm.cmd run build` | 对应 `npm run build`，构建到 `dist/` |
| `npm.cmd run test` | 对应 `npm run test`，运行机型数据、模型、事件与状态逻辑测试 |
| `npm.cmd run preview -- --port 5173 --strictPort` | 在构建后本地预览 `dist/` |

使用支持 WebGL 2 的现代桌面浏览器，并开启硬件加速。通过本地服务地址访问，不要直接双击 `index.html`。构建与逻辑测试不等于所有浏览器兼容性或真实物理精度已全部验收。已执行的检查见 [验证记录](docs/验证记录.md)。

## 当前功能

- **独立任务流程：**猎鹰 9 号保留官方 LEO 样例事件，其余型号采用明确标注的独立教学编排；点火、助推器分离、分级、抛罩与结束节点随构型变化。
- **构型差异：**长征五号 B 没有芯二级和二级点火；长征二号 F 展示逃逸塔与神舟飞船；星舰展示热分级，演示到 Ship 亚轨道阶段结束，不执行传统抛罩、卫星部署或着陆回收。
- **过程控制：**启动、暂停、恢复、重置、倍速和时间轴跳转；有载荷分离的任务在分离节点后保留几秒展示，再出现完成提示。
- **时间一致性：**时钟、进度条、事件刻度和当前/下一事件使用同一任务时间。切倍率先结算点击之前的时间；事件刻度按真实时刻定位，底部事件导航按发生顺序排列，回收示意也放在正确的时间位置。
- **回收与分离：**猎鹰 9 号、猎鹰重型提供独立教学回收情景；不回收的教学任务不开放回收追踪，也不把级段下落称为回收。型号具有回收设计能力，不等于当前教学任务包含回收。
- **六种视角：**自由环绕、箭体跟随、地面追踪、发动机视角、飞行全景、电影镜头。
- **结构探索：**展开、收拢、选择、聚焦和单独查看实际存在的模块，按机型提供说明，不给单芯级火箭凭空添加二级。
- **儿童讲解：**选中模块后点击“听讲解”，收听短句科普，支持暂停、继续、重听和“慢一点”。八型号 87 个模块共复用 29 段本地中文音频；切换模块或离开展厅会停止旧讲解。详细资料保留在“了解更多”中。
- **清晰选择：**以白色外衬、深色底线和彩色角标定位当前部件，保留真实涂装；剖视时只包围保留的几何，不重新显示已切去的外壳。
- **剖视图：**在“结构探索”切换“剖视图”，调整整箭剖面位置；选择部件后可聚焦或单独剖看。剖视保持装配状态，切回完整外观或发射模式自动恢复外壳。
- **明亮展厅：**结构探索与组装共用科技展厅、摄影工作室、火箭小工坊、星空展台四种主题。背景、地面和面板同步变化，工作室补光与反射让深色零件更容易辨认；不改变火箭本身的涂装。
- **组装工坊：**八款火箭均可逐块拼搭。“跟我搭”按步骤引导，“小工程师”按连接关系自由选择。拖动三维零件或侧栏卡片到发光位置，也可点击安装；支持提示、撤销、重新组装、完成奖励和接续发射。各型号进度与主题保存在本机浏览器。
- **现场环境：**大气与分层云、海面和沙岸、草灌与丘陵、热带植被或戈壁，以及地坪、围网、管线和不同类型服务塔。
- **音效：**默认关闭，可手动开启合成发动机音。

## 剖视与结构依据

剖视内部依据见 [剖视结构依据](docs/剖视结构依据.md)。已确认的推进剂布局用功能颜色区分，当前未核实的布局仅以灰色舱区范围显示。颜色不是实际推进剂外观；储箱长度、容积、管路和安装细节仍是教学近似，不补造未经确认的内部排列。模块详情内提供对应来源。

可在剖视中选择“单独查看当前模块”，此时剖面改以该模块中心定位；再次切换模块会自动聚焦。神舟与货运飞船示例显示公开舱段功能的教学摆放，其他未指定载荷不添加虚构的详细内装。“完整外观”“复原”或返回发射模式可恢复完整壳体。

储箱新增跟随剖面移动的功能填充、薄壁和穹顶截面。未知布局保持中性表达；级间补充环框与周边支撑，整流罩只显示壳层切边并保留载荷空腔。发动机供给泵与管路为代表性功能示意，不代表某型号的全部真实泵组或精确安装位置。

## 标准与电影画质

顶部可切换“标准”和“电影”。**电影档指浏览器实时高画质效果**：本地 CC0 HDR 天空光照与材质反射、4× MSAA 离屏抗锯齿、柔和 Bloom 泛光、阴影、微表面纹理和与模型喷口匹配的尾焰。电影镜头提供自动运镜，与画质档位分开选择；需要减轻显卡负担时可切回标准档。

高空地球使用本地 NASA Blue Marble 2002 历史合成影像（约 267 kB），按所选场地的经纬度设置球面方向。它提供全球远景，不代表场地测绘、当前地表或实时天气；来源见 [地球影像署名](public/assets/earth/ATTRIBUTION.md)。

电影档没有使用所选发射场的影视扫描资产，也不代表模型已具备工程结构精度。材质和镜头提升的是画面表现，不能替代真实结构、任务数据和设施测绘。

HDR 文件位于 `public/assets/environment/`，约 **6.4 MB**（6,397,400 字节），来自 Greg Zaal / Poly Haven，采用 CC0 授权；来源、授权与文件校验信息见 [ATTRIBUTION.md](public/assets/environment/ATTRIBUTION.md)。它用于光照、反射和天空表现，不是任一发射场的实拍全景。

依赖首次安装需要网络；安装完成后，运行所需模型、纹理、HDR 与程序资源从本地加载，无需在线外部素材服务。地图与资料链接由用户按需联网打开。

中文讲解音频约 26.7 MB，按点击加载单段，不会在进入页面时一次下载全部；播放不依赖电脑是否安装中文语音。文案与生成方式见 [本地讲解说明](public/assets/narration/README.md)。

| --- | --- |
| `空格` | 启动，或暂停／恢复发射过程 |

## 还原范围

官方公开尺寸提供的是整体尺度基准，当前没有完整工程图支持全部模块的精确长度、内部管路、连接机构和表面细节。拆解模式展示组成关系，不代表真实装配或飞行分离顺序。

组装工坊是基于现有模型的儿童拼搭玩法，完成顺序不代表工厂总装流程。详细交互与主题设计见 [主题与组装设计](docs/主题与组装设计.md)。没有倒计时或失败扣分，放错位置可继续尝试，也可随时用按钮完成安装。

猎鹰 9 号上升事件参考 SpaceX 用户指南的公开 LEO 样例；其他型号的事件时刻和全部轨迹、姿态、仪表数据为教学编排或插值。**回收动画是独立示意，不能与上升样例合称某次历史任务的完整复现。** 星舰教学任务的“完成”只表示亚轨道演示结束，不表示真实入轨或成功回收。

发射场的 Google Maps 入口仅提供概略位置参考。游戏没有抓取或打包 Google 底图，也没有将三维地形、道路、塔架和卫星影像配准；场景并非从谷歌卫星模型复制而来。设施布局和回收区域仍是区别化示意，并非 1:1 实际设施。

后续精度升级应先锁定具体任务，再逐项补充几何证据、同次任务时间轴与可获得的公开遥测。尚未核实的部分继续保留“示意”标记。
