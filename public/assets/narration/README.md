# 本地中文模块讲解

项目原创的儿童科普文案来自 `src/module-narration.js`。2026-10-01 使用本机已安装的 Microsoft Huihui Desktop 中文语音离线合成。八款火箭的 87 个模块按相同文案复用 29 段 WAV，总计 26,697,224 字节；22.05 kHz、16-bit、单声道。浏览器仅在点击讲解时从本地服务加载所选片段，不请求麦克风或在线语音服务。

讲解为合成语音，并非真人配音。文案对 5～10 岁儿童采用短句和比喻，事实范围与项目模块资料一致。内部尺寸、布局示意和未知项的详细说明仍可在模块资料中查看。

重新生成需要 Windows 已安装对应中文语音：先运行 `node scripts/generate-narration.mjs`，再在项目目录的 PowerShell 中运行 `./scripts/generate-narration.ps1`。生成脚本使用系统语音组件，受限执行环境可能需要正常的桌面进程权限；游戏播放已生成音频时无需这些工具或权限。文案与音频映射由 `src/narration-audio.js` 固定，测试会检测文案变更后尚未重新生成的过期音频。
